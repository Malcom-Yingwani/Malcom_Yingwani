About

A little bit about myself : Becoming a Software Developer

  • As long I Can Remember

    The Desire To Build

    "Tony Stark built this in a cave! With a box of scraps!" - Not Tony Stark

    Just like that my brain has been hooked eversince on the idea of building stuff. Physical or digital, doesn't matter, as long as I could build. For as long as I can remember I've had the urge to build.

  • 2023 - August 2025

    Frustration

    In order to pursue this end, I enrolled to study Mechanical Engineering — the jack of all trades concerning all things building — at the University of the Witwatersrand. For three years I was frustrated; frustrated at a theoratical course that only sought to get more theoratical as it progressed. Three years and I had built nothing. So in August of 2025, I left.

  • September 2025

    Embracing Software Development

    Theory about a hammer is good; as far as it equips you to hammer.

    What now? Software Development. A space where I would be allowed to build, a space I now realised I would love. I enrolled for the September 2025 cohort of the "Java Software Engineering" bootcamp programme offered by Code College ZA. Their practical, project based philosphy of learning was the selling piont.

Heritage Directory


Heritage Directory is a private church member directory built with ASP.NET Core Razor Pages and PostgreSQL. It provides a public-facing directory where members can be browsed and searched by name or family, alongside a secure admin dashboard for managing member records, family groupings, and profile photos. I worked primarily on the front end — building and styling the Razor Pages UI with Bootstrap — with some backend involvement in Entity Framework Core models and page logic.


Tech Stack

  • Razor Pages (HTML/CSS)
  • Bootstrap 5
  • C#
  • ASP.NET Core
  • Entity Framework Core
  • PostgreSQL

ReadUP


ReadUP is a full-stack web application built with Python and Django that allows users to add and manage books through authenticated accounts. The project focuses on practical backend development, including clean data models, CRUD operations, and Django’s built-in authentication system. It is deployed as a production-ready application with a simple, responsive interface.

The Post


The Post is a full-stack web application built with Node.js and Express that allows users to create blog posts through dynamic server-rendered pages. The project focuses on practical backend development, including structured routing, clean MVC architecture, database schema design with Mongoose. It integrates MongoDB for persistent data storage and is deployed as a production-ready application with a clean, responsive interface.


Tech Stack

  • Node.js, Express.js
  • MongoDB, Mongoose
  • EJS (Server-Side Rendering)
  • HTML5, CSS3, Bootstrap
  • JavaScript
  • Render (Deployment)

Downloads-Organiser


Downloads Organiser is a desktop automation script built with Python that automatically organizes a cluttered Downloads folder. Files are sorted into categorized directories based on type, with built-in duplicate handling (deleting identical files or renaming conflicting ones) and desktop pop-up notifications for successful moves or errors. The project demonstrates file system automation, error handling, and scheduled task integration for a practical, real-world workflow tool.

  • Python

Atlas Dev Tools


Atlas Dev Tools is a responsive front-end landing page built with vanilla JavaScript, HTML, and CSS as a practice MVP for a hypothetical developer productivity tool. It demonstrates core front-end fundamentals, UX flow, and product messaging without relying on any frameworks or backend integration.
